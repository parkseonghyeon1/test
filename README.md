# EclipseSkip - 이클립스: 더 어웨이크닝 Skip 자동 넘김

게임을 **창 모드**로 켜 두면 `Skip ▸|` 버튼이 뜰 때마다 자동으로 넘겨줍니다.
게임 창이 **다른 창에 가려져 있어도** 동작하고, 마우스·키보드·포커스를 뺏지 않아서 그동안 다른 작업을 할 수 있어요.

## 바로 실행하기

1. GitHub 저장소의 **Releases**에서 최신 `EclipseSkip.exe`를 다운로드합니다.
2. 더블클릭해서 실행합니다. Python은 설치하지 않아도 돼요.
   - **관리자 권한 확인 창(UAC)**이 뜨면 **예**를 누르세요. 게임이 관리자 권한으로 실행되기 때문에, 이 프로그램도 관리자 권한이어야 화면을 보고 입력을 보낼 수 있어요.
   - Windows SmartScreen이 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르세요. 서명되지 않은 exe라서 나오는 경고예요.

## 게임 창 크기를 바꿔도 동작해요

- 창 크기를 늘리거나 줄여도, 실행 중에 바꿔도 자동으로 맞춰서 Skip을 찾습니다. 로그에 "게임 화면 크기 변경"이 표시돼요.
- 16:9가 아닌 비율(예: 2560×1080 같은 가로로 넓은 창, 세로로 긴 창)도 지원합니다. UI가 창의 폭과 높이 중 어느 쪽을 따라 커지는지 둘 다 확인해요.
- 창이 커도 검사 속도는 거의 같아요. 큰 화면은 줄여서 검사하고, 한 번 맞은 배율을 기억해 두기 때문이에요.
- 아주 작은 창(가로 800px 미만)은 Skip 글자가 너무 작아져서 정확도가 떨어질 수 있어요.

## 화면 구성

| 영역 | 설명 |
|---|---|
| **상단** | 현재 상태(감시 중 / 일시정지 / 게임 찾는 중 / 최소화됨)와 **일시정지·시작** 버튼 |
| **게임 화면 미리보기** | 프로그램이 보고 있는 게임 화면입니다. Skip을 찾으면 금색 네모로 표시돼요. 미리보기가 계속 갱신되면 정상이에요. |
| **스킵 횟수 / 마지막 스킵** | 이번 실행에서 넘긴 횟수와 마지막으로 넘긴 시각 |
| **Skip 일치도** | 화면에서 Skip과 가장 비슷한 부분의 점수입니다. 흰 선(감지 기준)을 넘으면 넘깁니다. |
| **게임 창 정보** | 찾은 창, 화면 크기, 캡처 상태(PrintWindow: 가려져도 동작), 입력 방식, 권한 |
| **로그 탭** | 넘긴 기록과 안내 메시지 |
| **설정 탭** | 입력 방식, 감지 기준, 검사 주기, 미리보기 표시, 이 창을 항상 위에 등. 바꾸면 바로 적용되고 `settings.json`에 저장돼요. |
| **템플릿 탭** | Skip 이미지 목록. **지금 화면에서 추가**로 새 Skip 모양을 등록하거나, 직접 추가한 것을 삭제할 수 있어요. |

- **Ctrl+F10**: 어디서든 일시정지 / 재개
- **게임 창 화면 밖으로 숨기기**: 게임 창을 모니터 바깥으로 옮깁니다. 최소화와 달리 게임이 계속 화면을 그려서 감지가 유지돼요. 다시 누르거나 프로그램을 닫으면 원래 자리로 돌아옵니다. (실험 기능: 미리보기가 계속 움직이는지 확인하세요)

## 잘 안 될 때

- **Skip이 떠 있는데 일치도가 기준선을 못 넘음**
  템플릿 탭 → **지금 화면에서 추가**를 누르고, Skip 버튼과 아래 `Space` 라벨을 함께 드래그로 감싸 저장하세요. 다음 검사부터 같이 사용합니다.
- **감지는 되는데 넘어가지 않음**
  설정 → 입력 방식을 **클릭 메시지**로 바꿔 보세요. 그래도 안 되면 **최후 수단** 옵션을 켜세요. 게임 창을 0.1초 정도 앞으로 가져와 Space를 누릅니다.
- **캡처 방식이 "PrintWindow 실패"로 나옴**
  게임이 창 모드인지 확인해 주세요. 관리자 권한이 아니면 상단 배너의 **관리자 권한으로 다시 실행**을 누르세요.
- **최소화하면 멈춤**
  최소화하면 게임이 화면을 그리지 않아서 감지할 수 없어요. 최소화 대신 다른 창 뒤에 두거나 **숨기기** 버튼을 쓰세요.

## 개발

```bat
pip install -r requirements.txt
python app.py           :: GUI 실행
build_exe.bat           :: dist\EclipseSkip.exe 빌드
```

| 파일 | 역할 |
|---|---|
| `app.py` | tkinter GUI |
| `engine.py` | 백그라운드 스레드: 창 찾기 → 캡처 → 감지 → 입력, 설정 저장 |
| `detector.py` | OpenCV 템플릿 매칭 (창 폭·높이 기준 배율 후보 + 작업 해상도 + 배율 기억) |
| `win32_utils.py` | Windows API (PrintWindow 캡처, PostMessage 입력, 권한 확인, 창 이동) |
| `templates/` | 기본 Skip 이미지 (파일명의 `@1244`·`@1244x700`은 잘라낸 당시 게임 화면 크기) |
| `tests/win_selftest.py` | Windows CI 자가 테스트 |
| `tests/test_detector_resize.py` | 창 크기·비율 변화 감지 테스트 (합성 화면) |

코드를 push하면 GitHub Actions(`.github/workflows/build-exe.yml`)가 Windows에서 테스트·빌드한 뒤 Releases에 exe를 올립니다.

## 주의

자동 입력 프로그램은 게임 운영 정책(약관)에 따라 제재 대상이 될 수 있습니다. 사용 전에 약관을 확인하세요.
