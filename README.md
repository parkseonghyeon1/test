# 이클립스: 더 어웨이크닝 - Skip 자동 클릭기

게임을 **창 모드**로 켜 두면 화면에 `Skip ▸|` 버튼이 뜰 때마다 자동으로 넘겨줍니다.
게임 창이 **다른 창 뒤에 가려져 있어도** 동작하고, 마우스·키보드·포커스를 뺏지 않아서 그동안 다른 작업을 할 수 있어요.

## 동작 방식

1. `PrintWindow` API로 게임 창 화면만 캡처합니다. 다른 창에 가려져 있어도 캡처돼요.
2. 화면 오른쪽 35% 영역에서 `templates/` 폴더의 Skip 이미지를 OpenCV 템플릿 매칭으로 찾습니다.
   - 컷신, 퀘스트 대사, 하단 대화창용 Skip 3종이 기본으로 들어 있어요.
   - 창 크기가 바뀌어도 자동으로 비율을 맞춥니다.
3. 찾으면 `PostMessage`로 게임 창에 **Space 키** 메시지를 보냅니다. 포커스는 이동하지 않아요.
   - Space가 먹히지 않으면 같은 위치에 **클릭 메시지**를 보내는 방식으로 자동 전환합니다.

## 설치 / 실행 (Windows 10/11)

```bat
:: Python 3.10 이상 필요
pip install -r requirements.txt
run.bat
```

또는 `python skip_bot.py`로 실행하세요.

- **Ctrl + F10**: 일시정지 / 재개
- **Ctrl + C** (콘솔 창에서): 종료

> 게임을 관리자 권한으로 실행했다면 이 프로그램도 **관리자 권한**으로 실행해야 입력이 전달됩니다.
> (Windows에서는 권한이 낮은 프로그램이 높은 권한 창에 메시지를 보낼 수 없어요.)

### exe로 만들기

`build_exe.bat`을 실행하면 `dist\EclipseSkip.exe`가 만들어집니다. 실행할 때 `templates` 폴더가 exe 옆에 있어야 해요.

## 옵션

| 옵션 | 설명 |
|---|---|
| `--method auto\|key\|click\|foreground` | 입력 방식 (기본 `auto` = key → click 자동 전환) |
| `--allow-foreground` | key/click이 모두 안 먹힐 때 게임 창을 **0.1초 정도 앞으로 가져와** 실제 Space를 누른 뒤 원래 창으로 돌아갑니다. 잠깐 포커스가 바뀌니 최후 수단으로만 쓰세요. |
| `--threshold 0.75` | 감지 기준 (0~1). 오탐이 있으면 올리고, 못 찾으면 내리세요. |
| `--interval 0.4` | 화면 검사 주기 (초) |
| `--title 이클립스` | 게임 창 제목에 들어간 글자 |
| `--debug` | 매 프레임 점수를 출력하고, 감지한 화면을 `debug/` 폴더에 저장 |
| `--capture` | 지금 화면에서 Skip 영역을 드래그로 잘라 새 템플릿으로 저장 |

## 잘 안 될 때

- **감지가 안 됨** (`--debug`로 실행했을 때 best 점수가 낮음)
  Skip이 떠 있는 상태에서 `python skip_bot.py --capture`를 실행하세요. 창이 뜨면 `Skip ▸|`와 그 아래 `Space` 라벨을 함께 드래그로 감싸고 Enter를 누르면 됩니다.
  `templates/custom_…png`로 저장되고, 다음 실행부터 같이 사용합니다. 기본 템플릿은 첨부된 스크린샷에서 잘라낸 거라, 직접 캡처한 템플릿이 더 정확해요.
- **감지는 되는데 넘어가지 않음**
  게임이 백그라운드 메시지를 무시하는 경우예요. `--method click`을 먼저 시도해 보고, 그래도 안 되면 `--allow-foreground`를 쓰세요.
- **"캡처 화면이 검은색"이라고 나옴**
  게임이 전체화면/독점 모드인 경우예요. 창 모드로 바꿔 주세요.
- **게임 창을 최소화하면 동작하지 않음**
  최소화하면 게임이 화면을 그리지 않아서 캡처할 수 없어요. 최소화 대신 다른 창 뒤에 두세요.

## 주의

자동 입력 프로그램은 게임 운영 정책(약관)에 따라 제재 대상이 될 수 있습니다. 사용 전에 약관을 확인하세요.
